# Parallax Scrolling Website

A front-end web project focused on exploring and implementing the Parallax Scrolling effect.

## About the Project

This project was developed to experiment with Parallax Scrolling, a visual technique that creates an illusion of depth and movement by making background and foreground elements move at different speeds while scrolling.

The main goal was to explore how this effect can enhance visual storytelling and create a more immersive browsing experience.

## Main Feature

- Parallax Scrolling Effect
- Layered visual elements
- Dynamic scrolling experience
- Focus on visual design and user interaction

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was created as a practical experiment to understand and implement parallax effects in front-end web development.
